# Mi Primera Web

Proyecto de práctica para aprender los fundamentos del desarrollo web con **HTML**, **CSS** y **JavaScript**.

## Contenido del proyecto

- **`index.html`**: página principal con ejemplos de HTML semántico (encabezados, enlaces, imágenes, listas, tablas y formularios).
- **`perfil.html`**: página "Sobre mí" con presentación, hobbies, habilidades y formulario de contacto.
- **`calc.html`** + **`calc.js`**: calculadora web básica en JavaScript.
- **`styles.css`**: estilos generales y maquetación con Flexbox.
- **`script.js`**: cambio entre modo claro y modo oscuro con persistencia en `localStorage`.

## Cómo verlo

1. Clona o descarga el repositorio.
2. Abre `index.html` directamente en tu navegador (o usando una extensión como Live Server).
